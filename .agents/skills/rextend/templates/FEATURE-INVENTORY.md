## Inventory rules

- Split large capabilities into testable subfeatures.
- Record hidden/admin/API/background functionality, not only visible screens.
- Link each feature to at least one workflow, source location, API or test when discovered.
- Do not mark a feature verified based only on a UI label or README statement.
- Record known differences and unsupported edge cases explicitly.
